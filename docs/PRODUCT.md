# PRODUCT — English Speaking Coach v1

## 一句話

多鄰國的題型，雅思家教的回饋：看到題目，單字卡輔助，**必須開口說**。

## 用戶

- 海猫：想練英文口說對話，要常見文法＋單字，用繁中溝通
- 延伸：任何想每天練 10 分鐘口說的中文母語者

## 核心迴圈

1. 看題（英文＋中文＋文法點）
2. 點單字卡聽發音，跟讀
3. 按麥克風，用說的組句回答
4. Agent 轉寫 → 改文法＋發音＋給更好的說法 → 下一題

## v1 範圍

- 3 堂課：現在簡單式（習慣）、過去式（昨天）、現在進行式（現在）
- 每課：1 文法點＋1 問句＋4 張單字卡＋1 例句
- 桌面版 pane＋主對話語音（STT）＋TTS 跟讀
- 家教 skill：固定流程，不隨便跳題

## 不做（v1）

- 發音自動評分（要模型支援，先用人改）
- 登入/同步/手機版
- 題庫後台（先改 JSON）

## 成功標準

- 連續 7 天每天練 1 課
- 每課能不看卡片說出 3 個正確句子
- 過去式/三單 -s 錯誤率下降

## v2 候選

- 分級測驗（A1–B1）＋錯題本
- 每日複習 cron 推播
- 情境對話包：餐廳、面試、旅遊、醫院

## 技術

- Hermes desktop plugin（plain ESM，jsx calls）
- STT：本地 faster-whisper / Groq / OpenAI
- TTS：Edge（免費預設）/ speechSynthesis（pane 內）
- 題庫：`lessons/lessons.json`，pane 跟 skill 共用
